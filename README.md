# 🌱 RAÍCES — Plataforma Web

**RAÍCES** es un proyecto colaborativo de desarrollo web realizado por un equipo de tres integrantes. Este repositorio reúne el código fuente y la estructura de la aplicación, incluyendo las carpetas del frontend y backend.

## 📌 Acerca del proyecto

RAÍCES es una iniciativa desarrollada en equipo como parte de un proceso de formación en desarrollo web. El proyecto permite poner en práctica habilidades de programación, organización del código y colaboración.

## 🛠️ Tecnologías

Entre las tecnologías identificadas inicialmente en el repositorio se encuentran:

- JavaScript
- PHP
- Desarrollo frontend y backend

La lista se actualizará después de verificar los frameworks y las dependencias que utiliza el proyecto.
